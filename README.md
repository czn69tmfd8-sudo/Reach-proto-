# Reach-proto-
Making love not feel so distant. 

## Product direction and native milestone

REACH is organized around **Our Connection**, **My Private Coach**, and **Our Growth**.
Private coaching and shared goals are documented future work, not implemented features.
The immediate milestone remains a verified real audio/video call between two iPhones.
